# Focalis Privacy Notice

Last updated: 2026-08-11

Focalis is designed as a local-first desktop application. Normal Design, Source, Wave, Trace,
Schematic, and Code workflows process project data on the user's computer.

## Data Stored Locally

Focalis may store settings, workspace state, indexes, waveform caches, sessions, logs, trial state,
and licensing state under the user's Windows profile or selected workspace. Uninstalling the
application may not remove user-created projects or all application data.

## Network Features

Network access occurs only for features that require it, including update checks, user-configured AI
providers, external MCP clients or servers, and future licensing operations. Requests may disclose
ordinary network metadata such as IP address, client version, and request time to the selected
service provider. Provider-specific terms apply when you configure an external service.

Focalis does not intentionally upload RTL, source paths, waveform contents, or Trace results during
ordinary local debugging. No product analytics or crash-reporting telemetry is enabled by default in
the current Public Beta.

## User Control

Do not enter provider credentials into issue reports. Review configured providers and MCP permissions
before enabling networked workflows. Remove local application data and revoke external credentials
when a machine or account is retired.

Material changes to this notice will be published in this repository and reflected in a later Focalis
release.
