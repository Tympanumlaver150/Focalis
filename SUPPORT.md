# Focalis Support

Focalis Public Beta support is provided through
[this repository's GitHub Issues](https://github.com/DawnCarol/Focalis/issues).

Before opening an issue:

1. reproduce the problem with the latest published Beta;
2. check whether an included example reproduces it;
3. record the complete Focalis and Windows versions;
4. include the first actionable Message diagnostic and concise reproduction steps;
5. remove proprietary RTL, credentials, user names, and private filesystem paths.

For performance reports, include the dump format and approximate size, the selected hierarchy scope,
signal count, and whether the operation was a cold open or warm repeat.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be posted as public
issues. The Public Beta has no guaranteed service-level agreement.
