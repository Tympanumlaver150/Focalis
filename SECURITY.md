# Focalis Security Policy

## Supported Versions

Security fixes are provided only for the latest published Focalis Public Beta. Older Beta builds may
be superseded without receiving separate fixes.

## Reporting A Vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/DawnCarol/Focalis/security/advisories/new)
for this repository. Do not disclose a suspected
vulnerability, exploit, credential, proprietary RTL, or private filesystem path in a public issue.

Include the affected Focalis version, impact, prerequisites, minimal reproduction steps, and any
proposed mitigation. Allow reasonable time for validation and remediation before public disclosure.

General correctness, compatibility, or performance bugs that do not create a security impact should
be reported through the normal support process in [SUPPORT.md](SUPPORT.md).
